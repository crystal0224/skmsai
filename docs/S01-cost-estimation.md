## 5. 비용 최적화 전략

### 캐싱 효과
- QueryCache (LRU, TTL 5분, 256 엔트리) 적용 시 중복 쿼리 제거
- 예상 캐시 히트율: 20~40% → 월 비용 20~40% 절감

### 모델 다운그레이드
- Query Routing → Haiku ($0.25/$1.25 per 1M): 쿼리당 ~$0.0004 (85% 절감)
- LLM Judge → Haiku: 평가당 ~$0.002 (83% 절감)

### 로컬 모델 대안

| 용도 | 클라우드 모델 | 로컬 대안 | 최소 VRAM | 한국어 품질 |
|------|-------------|-----------|-----------|-----------|
| Query Routing | Sonnet | Qwen2.5-7B | 16GB | 충분 |
| 답변 생성 | Sonnet | Qwen2.5-72B | 80GB+ | 보통~양호 |
| LLM Judge | Sonnet | Qwen2.5-32B | 40GB+ | 보통 |
| 임베딩 | text-embedding-3-large | multilingual-e5-large | 4GB | 양호 |

> **주의**: 로컬 모델은 한국어 경영 용어(SUPEX, VWBE, SK-Manship 등)의 정확한 이해와
> 인용이 클라우드 모델 대비 떨어질 수 있음. 특히 답변 생성에서 품질 차이가 큼.
> GPU 서버 비용(A100 80GB 기준 월 $1,500~$2,500)이 API 비용보다 높을 수 있으므로
> 월 쿼리 5만 건 이상일 때만 경제적.
