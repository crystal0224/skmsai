## 4. 정규식 후보 3개

### 후보 A: 보수적 (Conservative)

```regex
^\s*(?:(\d{4})년\s+(초판|\d{1,2}차)|(\d{1,2})차\s+(\d{4})년)\s*(?:\|.*)?$
```

**동작 원리:**
- `YYYY년 초판` 또는 `YYYY년 N차` 또는 `N차 YYYY년` 매칭
- `\|` 뒤 부가 정보(전면보완 등) 허용
- **줄 끝(`$`) 앵커** 사용 → 뒤에 산문이 이어지면 매칭 안 됨

**매칭 결과 (12개 전부 매칭, 오탐 0개):**
| 라인 | 원문 | 매칭? |
|------|------|-------|
| 11 | `1979년 초판` | **YES** |
| 727 | `1981년 1차 ` | **YES** |
| 5251 | `5차 1988년 ` | **YES** |
| 6749 | `6차 1989년 ` | **YES** |
| 7860 | `7차 1990년 \| 전면보완` | **YES** |
| 7899 | `1989년 12월  ` | NO (12월 ≠ N차) |
| 7939 | `1979년 3월  ` | NO (3월 ≠ N차) |
| 8954 | `8차 1995년` | **YES** |
| 10132 | `9차 1997년 ` | **YES** |
| 11778 | `1998년 10차 ` | **YES** |
| 12741 | `1979년 SKMS를 정립하고...` | NO (산문 후속) |
| 12937 | `2004년 11차 \| 전면 보완` | **YES** |
| 13959 | `2008년 12차` | **YES** |
| 13987 | `2008년 주요 개정 내용` | NO ("주요" ≠ N차) |
| 14947 | `2016년 13차 \| 전면보완` | **YES** |
| 15073 | `2020년 14차` | **YES** |

| 지표 | 값 |
|------|-----|
| 정탐(True Positive) | 12/12 (100%) |
| 오탐(False Positive) | 0 |
| 미탐(False Negative) | 0 |

**장점:** 오탐 제로. 줄 끝 앵커로 산문 내 연도 언급을 완벽 차단.
**단점:** 향후 `15차` 등이 `2025년 15차 개정판` 형식이면 "개정판" 단어 때문에 `$` 앵커에서 미탐 가능. 단, `\s*(?:\|.*)?$`가 `|` 뒤를 처리하므로 `|` 없이 뒤에 "개정판" 등이 오면 미탐.

### 후보 B: 중간 (Moderate) ← **추천**

```regex
^\s*(?:(\d{4})년\s+(초판|\d{1,2}차)|(\d{1,2})차\s+(\d{4})년)
```

**동작 원리:**
- 후보 A와 동일한 핵심 패턴
- **줄 끝 앵커 없음** → 뒤에 `| 전면보완`, `개정판`, 공백 등 무엇이 와도 매칭
- 핵심 판별: `YYYY년` 뒤에 반드시 `초판` 또는 `N차`

**매칭 결과 (12개 전부 매칭, 오탐 0개):**
| 라인 | 매칭? | 이유 |
|------|-------|------|
| 11 | **YES** | `1979년 초판` |
| 727 | **YES** | `1981년 1차` |
| 5251 | **YES** | `5차 1988년` |
| 6749 | **YES** | `6차 1989년` |
| 7860 | **YES** | `7차 1990년` |
| 7899 | NO | `1989년 12월` — "12월"은 `\d{1,2}차`에 매칭 안 됨 |
| 7939 | NO | `1979년 3월` — "3월"은 매칭 안 됨 |
| 8954 | **YES** | `8차 1995년` |
| 10132 | **YES** | `9차 1997년` |
| 11778 | **YES** | `1998년 10차` |
| 12741 | NO | `1979년 SKMS` — "SKMS"는 매칭 안 됨 |
| 12937 | **YES** | `2004년 11차` |
| 13959 | **YES** | `2008년 12차` |
| 13987 | NO | `2008년 주요` — "주요"는 매칭 안 됨 |
| 14947 | **YES** | `2016년 13차` |
| 15073 | **YES** | `2020년 14차` |

| 지표 | 값 |
|------|-----|
| 정탐(True Positive) | 12/12 (100%) |
| 오탐(False Positive) | 0 |
| 미탐(False Negative) | 0 |

**장점:**
- 오탐 제로 + 미탐 제로
- 줄 끝 앵커가 없어서 향후 `2025년 15차 개정판` 같은 형식도 매칭
- 보완 이력 테이블의 `'YY.MM.DD` 패턴을 완전히 무시 (type_c 제거)
- 핵심 판별자(`초판` / `N차`)만으로 오탐/미탐 모두 방지

**단점:**
- 이론적으로 본문 중 `"1979년 초판에 정립된..."` 같은 산문이 줄 시작에 오면 오탐 가능. 단, `^\s*` 앵커로 줄 맨 앞에서 시작하는 경우만 매칭하므로, 15,330줄 전수 조사 결과 이런 케이스 없음.

### 후보 C: 공격적 (Aggressive)

```regex
^\s*\d{4}년\s+
```

**동작 원리:**
- `YYYY년`으로 시작하는 모든 줄을 매칭
- 뒤에 무엇이 오든 상관없음

**매칭 결과:**
| 지표 | 값 |
|------|-----|
| 정탐(True Positive) | 7/12 (58.3%) — type_b 5건 미탐 (역순 `N차 YYYY년` 형식) |
| 오탐(False Positive) | **7건** (7899, 7939, 11832, 12741, 13987, 14965, 15085) |
| 미탐(False Negative) | 5건 (5251, 6749, 7860, 8954, 10132: 모두 `N차 YYYY년`) |

**장점:** 구현 단순.
**단점:** 오탐 7건 + 미탐 5건. type_b 형식 전부 누락. 서명 날짜, 산문 문장, 소제목이 모두 잡힘. 후처리 필터 필수.

## 6. 장/절(Chapter/Section) 헤더 패턴 실측

### 현재 config vs 실측 비교

| 레벨 | 현재 config 패턴 | 실제 매칭 수 | 상태 |
|------|-----------------|------------|------|
| H0 | 개정판 경계 | 12개 | **완료** (type_a + type_b, type_c 제거) |
| H1 | `^\s{0,3}(서문\|序文\|경영\s*(...)\|...)` | ~40개 | **완료** (한글 장 제목) |
| H2 | `^\d{1,2}\.\s+[가-힣]` | 다수 | 유지 |
| H3 | `^(가\|나\|다\|...\|아)\.\s+` | 다수 | 유지 |
| H4 | `^\(\d{1,2}\)\s+` | 364개 | 유지 |
| H4b | `^\d{1,2}\)\s+[가-힣]` | ~20개 | **완료** (반괄호 번호) |

### 실측된 장(Chapter) 수준 헤더 (L0 → 신규 H1)

장 수준 헤더는 **번호 없는 순수 한글 제목**으로, 선행 공백이 있거나 없다:

```
서문 / 序文
경영 기본 이념 / 경영기본이념
경영 원칙 / 경영원칙
경영 관리 요소 / 경영관리요소
경영 실행 원리 / 경영실행원리
기업관
추구 가치
SUPEX 추구법 / SUPEX 추구 방법
SUPEX 목표/실행전략
SUPEX 추구 환경 조성
동적 요소 / 정적 요소
패기
```

제안 패턴:
```regex
^\s{0,3}(서문|序文|경영\s*(기본\s*이념|원칙|관리\s*요소|실행\s*원리|기본이념|관리요소|실행원리)|기업관|추구\s*가치|SUPEX|정적\s*요소|동적\s*요소|패기)
```

### 실측된 `N) text` 패턴 (신규 H4b)

1) 기획관리
