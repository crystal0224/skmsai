# Content Studio Phase 7: SKMS 의미론적 시각화 고도화 계획 (2026-03-12)

본 계획은 사용자가 SKMS의 텍스트 데이터 이면에 숨겨진 경영 철학의 구조와 역사적 변천을 시각적으로 통찰할 수 있도록 돕는 고도화 로드맵입니다.

## 1. 3대 핵심 시각화 모델 (Visualization Models)

### Task 1: 경영 요소 관계 그래프 (Entity-Relationship Graph)
- **목표**: VWBE, SUPEX, 행복, 이해관계자 등 핵심 개념 간의 유기적 관계 시각화.
- **구현**: AntV G6를 활용한 인터랙티브 네트워크 맵. 사용자가 노드를 클릭하면 관련 SKMS 원문 팝업 노출.

### Task 2: 철학 진화 타임라인 (Philosophy Evolution Timeline)
- **목표**: 1979년 초판부터 2020년 14차 개정판까지의 핵심 문구 변화 추적.
- **구현**: 나란히 배치된 타임라인 차트. 개념의 신설(Created), 수정(Modified), 삭제(Removed) 상태를 컬러 코딩으로 표시.

### Task 3: 경영 요소 밸런스 레이더 (Management Element Radar)
- **목표**: 특정 판본이나 주제 내에서 '인간 위주' vs '경영 원칙' 등 요소별 비중 분석.
- **구현**: LLM이 텍스트의 가중치를 분석하여 레이더(방사형) 차트로 변환.

## 2. 기술적 구현 방안
- **Data Extractor Agent**: 시각화 전용 에이전트를 추가하여 텍스트에서 `nodes`와 `edges` 데이터를 JSON으로 추출.
- **Visualization Studio UI**: 
    - 사용자가 직접 차트 유형을 선택하고 데이터를 필터링할 수 있는 전용 탭 추가.
    - 생성된 차트를 PPTX에 고화질 이미지로 자동 삽입하거나 HTML로 내보내기.

## 3. 기대 효과
- **분석 시간 단축**: 수천 페이지의 개정 이력을 시각화 한 번으로 파악 가능.
- **설득력 강화**: 데이터에 기반한 정교한 시각 자료를 교육 및 보고에 즉시 활용.
