# Content Studio Phase 6: 전문 저작 도구 및 멀티미디어 고도화 계획 (2026-03-12)

본 계획은 SKMS AI Studio를 단순 생성 도구에서 전문가용 '인터랙티브 저작 워크스페이스'로 격상시키고, 영상 콘텐츠까지 아우르는 멀티미디어 능력을 갖추기 위한 최종 로드맵입니다.

## 1. 4대 핵심 과제 (Strategic Tasks)

### Task 1: Human-in-the-Loop (편집기 및 부분 재생성)
- **목표**: AI가 만든 초안을 사용자가 직접 교정하고 의도를 반영할 수 있는 협업 환경 구축.
- **수행**: 
    - 중간 생성물(Plan JSON) 편집 기능 제공.
    - 특정 슬라이드/카드만 다시 생성하는 'Surgical Edit' 기능 구현.

### Task 2: Video Studio (자동 영상 강의 생성)
- **목표**: 생성된 슬라이드와 오디오를 결합하여 즉시 배포 가능한 영상 콘텐츠(.mp4) 생산.
- **수행**: 
    - 서버 내 `ffmpeg` 라이브러리 탑재.
    - 슬라이드-오디오 싱크 합성 엔진 구축.

### Task 3: Deep Grounding (상세 출처 및 신뢰성 시각화)
- **목표**: 생성된 모든 문장에 대해 원문의 정확한 근거(페이지, 조항)를 제시하여 신뢰도 극대화.
- **수행**: 
    - 메타데이터에서 원문 페이지 번호 및 하이퍼링크 추출.
    - PPTX 발표자 노트 및 마지막 슬라이드에 '상세 근거 맵' 자동 생성.

### Task 4: Targeted Content Engine (타겟 맞춤형 최적화)
- **목표**: 신입사원부터 임원까지, 학습 대상의 눈높이에 맞는 용어와 논리 구조 자동 적용.
- **수행**: 
    - 옵션 내 `target_audience` 필드 추가.
    - 4단계 에이전트(전략/카피/디자인/검수) 전체 프롬프트에 타겟팅 로직 주입.

## 2. 세부 일정
- **Day 1 (현재)**: Task 4 (타겟팅 엔진) 및 Task 3 (상세 출처 로직) 완료.
- **Day 2**: Task 1 (플랜 편집 API 및 UI 연동) 구현.
- **Day 3**: Task 2 (비디오 합성 엔진) 및 최종 E2E 검증.

## 3. 성공 지표
- 사용자 개입도: 생성된 콘텐츠의 30% 이상을 사용자가 직접 편집하여 최종 확정 가능.
- 콘텐츠 확장성: 단일 요청으로 PPTX, PNG, MP4 동시 생산 성공률 100%.
- 신뢰도: 모든 슬라이드에 1개 이상의 직접적인 원문 페이지 출처 명기.
