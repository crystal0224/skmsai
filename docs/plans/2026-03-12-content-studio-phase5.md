# Content Studio Phase 5: 하이엔드 품질 고도화 계획 (2026-03-12)

본 계획은 컨텐츠 스튜디오의 결과물을 전문가(Consultant/Designer) 수준으로 끌어올리기 위한 최상위 정제 단계입니다.

## 1. 5대 핵심 과제 (High-End Tasks)

### Task 1: 강의자료 멀티 에이전트 체제 도입
- **목표**: 강의의 논리적 흐름(Storytelling)을 강화하고 카피의 품질을 극대화.
- **수행**: Strategist(구조) -> Copywriter(텍스트) -> Art Director(시각화) 3단계 협업 파이프라인 구축.

### Task 2: 의미 기반 지능형 레이아웃 (Semantic Layouts)
- **목표**: 텍스트의 논리 구조(단계, 비교, 나열, 관계)를 파악해 최적의 도식 적용.
- **수행**: 프로세스형(화살표), 매트릭스형(4분면), 관계도형(순환) 레이아웃 엔진 추가.

### Task 3: 지능형 슬라이드 분할 (Auto-Splitting)
- **목표**: 폰트 크기를 유지하면서 가독성을 확보하기 위해 내용 과부하 시 슬라이드 자동 분리.
- **수행**: 토큰/자수 기반 분할 로직 및 "Continued" 슬라이드 연결 기술 적용.

### Task 4: 벡터 아이콘 라이브러리 통합
- **목표**: 실사 이미지보다 정갈한 기업용 도식화를 위해 고품질 SVG 아이콘 배치.
- **수행**: 산업별/개념별 아이콘 매핑 시스템 및 PPTX 쉐이프 삽입 로직 강화.

### Task 5: AI 디자인 비평 루프 (Vision Critique)
- **목표**: 생성된 결과물의 최종 시각적 결함을 AI가 스스로 검수하고 수정.
- **수행**: 생성된 슬라이드 이미지를 Multimodal LLM으로 분석하여 가독성/배치 개선 피드백 반영.

## 2. 세부 일정
- **Day 1 (현재)**: Task 1 (멀티 에이전트 확장) 및 Task 3 (분할 로직 기초) 완료.
- **Day 2**: Task 2 (지능형 레이아웃) 및 Task 4 (아이콘 시스템) 구현.
- **Day 3**: Task 5 (비전 비평 루프) 및 최종 E2E 품질 검증.

## 3. 예상 품질 수준
- 가독성: 14pt 미만 폰트 사용률 0%.
- 디자인 일관성: 전체 슬라이드 간 헤더/거버닝 메시지 오차 0px.
- 논리 구조: 단순 불릿 포인트 나열 탈피, 50% 이상의 슬라이드 도식화 적용.
